# Sticker Benzi — GitHub Pages Demo

این پوشه نسخه نمایشی Frontend پروژه استیکر بنزی است که برای مشاهده صفحات روی GitHub Pages آماده شده است.

## انتشار
1. یک Repository جدید در GitHub بسازید (مثلاً `sticker-benzi-demo`).
2. **محتویات همین پوشه** را مستقیماً در ریشه Repository آپلود کنید؛ خود پوشه را داخل یک پوشه دیگر قرار ندهید.
3. از Settings → Pages، گزینه Deploy from a branch را انتخاب کنید؛ Branch را `main` و Folder را `/ (root)` بگذارید و Save کنید.
4. پس از انتشار، آدرس `https://USERNAME.github.io/REPOSITORY/` را برای مشتری بفرستید.
5. پنل مدیریت دمو: `https://USERNAME.github.io/REPOSITORY/admin/` یا `.../admin/index.html`

## ورود به پنل دمو
- نام کاربری: `demo`
- رمز عبور: `demo1234`

## محدودیت‌های نسخه نمایشی
- این نسخه فقط Frontend است و Node.js، Express یا MariaDB ندارد.
- داده‌ها نمونه هستند و ممکن است با آخرین اطلاعات واقعی دیتابیس یکسان نباشند.
- عملیات نمایشی پنل در `localStorage` همان مرورگر ذخیره می‌شود؛ روی سیستم مشتری به دیتابیس اصلی منتقل نمی‌شود.
- آپلود تصویر واقعی روی سرور انجام نمی‌شود؛ مسیر تصاویر نمونه از فایل‌های موجود در پروژه استفاده می‌کند.
- آمار پنل، داده‌های ساختگی برای نمایش رابط کاربری است و آمار واقعی سایت نیست.
- سفارش‌ها فقط لینک‌های تماس WhatsApp و Bale را باز می‌کنند؛ ثبت سفارش سمت سرور انجام نمی‌شود.

**این نسخه را فقط برای پیش‌نمایش به مشتری بفرستید، نه برای استفاده عملیاتی یا دریافت سفارش واقعی.**
